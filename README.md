# 观市 · 财经信息聚合平台

当前版本 1.7：[打开观市](https://wansuliu2004-afk.github.io/guanshi-market-daily/)。实时新闻与每日收盘报支持来源短摘要，保留出处链接。云端每 5 分钟计划触发采集，电脑关机不影响。配置与备份说明见 [免费上线说明.md](免费上线说明.md)。

## 实时与日报

页面顶部可切换两种内容，日期与筛选仍可使用，切换地址可直接分享：

- **实时追踪**：保留最新报价、跨市场行情和按热度及时效更新的新闻 Top 20。
- **每日收盘报**：从该北京时间日期内全部已采集候选中筛选重要财经新闻前 20，不做时效衰减。跨站覆盖 35%、源内互动分位 25%、来源重点标记 25%、宏观政策与行业影响关键词 15%，属于算法筛选，不是人工定论或全网完整覆盖。不足 20 条不补造。
- **收盘盘面独立保存**：四个 A 股指数均为当日 15:00 后报价，上证完整分时及当日日 K 到齐，且上证收盘价相互核对一致后，锁定独立快照。盘面、成交额、行业资金和涨停统计按该次采样保存，展示实际采集时间；后续最新报价不覆盖日报。跨市场概览在实时与日报中均可查看：日报独立保存各市场当日最后留存报价，卡片标注真实报价日期，海外隔夜和国债日度数据不冒充统一收盘。跨日后固定，旧日报只从自己的同日归档补齐概览，不使用今天的数据填历史。
- **晚间新闻继续纳入**：当日日报显示“更新中”，包含已采集到的盘后与晚间标题；午夜补采完成后定稿，之后不重排历史。无需手动发布日报。历史日期的直接链接默认打开日报。
- **旧日档迁移**：用已保留的当日完整候选重建日报，不覆盖原实时归档。旧盘面注明由当日留存数据整理；缺少可核对的收盘数据会明确提示，不能拿盘中或其他日期代替。

日报文件为 `data/reports/YYYY-MM-DD.json`，公开文件为 `daily/YYYY-MM-DD/report.json`，本机接口 `GET /api/report?date=YYYY-MM-DD`。`lib/reports.mjs` 负责全日筛选、独立收盘保存和跨日定稿。所有原有历史文件继续保留，备份时保留整个 `data/`。

自动采集只覆盖程序实际获取的候选；首次建站在 2026-11-09，早于开始采集时间的消息不能声称已经完整覆盖。当前交易日判断只明确识别周末；节假日或源缺数会显示暂无可确认收盘数据，未自行推测交易日。

默认展示真实公开来源的财经标题及行情采样。新闻包含**标题 + 来源 + 来源提供的独立短摘要（有则显示）+ 原文链接**，以及发布时间、采集时间、去重与排序所需的元数据。摘要只从财联社 `brief`、东方财富 `digest/simdigest` 字段提取，清理格式后最多 140 个字符；不从正文生成摘要。没有独立摘要的来源仍只显示标题和链接。新闻正文和原始响应不落盘、不通过本站 API 返回。

点击标题或来源直接跳转原站；点击单独的“关联板块”按钮联动盘面。聚合标题没有站内阅读全文页。

行情卡片可直接跳转对应报价来源；分时 / 日 K、行业与资金、涨停池均有来源入口。资金排行每行也有板块来源链接，原有点击筛选资讯的操作保留。

## 自动更新和历史回看

**不用每天发消息要求更新。** 免费云端方案使用 GitHub Pages 展示网页、GitHub Actions 每 5 分钟计划触发采集，与个人电脑是否开机无关，历史保存在专用分支。定时任务可能延迟，网页显示真实采集时间与异常状态。当前公开部署已完成，复制到新账号时仍需按说明完成首次部署。

本机预览仍可运行 `node server.mjs`，每 5 分钟自动采集一次；这个本机模式受电脑开关影响。页面会区分“本地服务”和“云端定时”，不会把本机预览标成已上线。

建站日为 **2026-11-09（北京时间）**。日期区显示建站时间、已保存天数、“已有记录”和“回到今天”。不补造建站前历史。

当天将标题 Top 20、来源链接和时间、全部已取得行情、分时、日 K、板块资金、涨停数据及事实结论合并存入 `data/archive/YYYY-MM-DD.json`。全日统计截止北京时间当日24:00；次日00:15以后首轮采集，从源列表和已保存候选补入午夜前发布的标题，再固定新闻榜单。行情仍保留当日最后实际报价时间。后续不修改已完成午夜补采的榜单。因此明天选 9 号仍能看到 9 号的情况。服务重启直接读取硬盘归档，不依赖浏览器缓存。

建站前发布的资讯可以在原始采集缓存中出现，但不列入建站后日档目录。服务中断期间没有采集到的数据不会自动补齐，空日期会明确提示。日档会长期保留；迁移、重装或部署时必须一起保留整个 `data/` 目录。

## 启动

需要 Node.js 20 或以上，无需 npm 安装依赖：

```sh
node server.mjs
```

打开 **http://127.0.0.1:4173**。Windows 可双击 `启动观市.cmd`。启动时先采集一次，随后每 5 分钟采集；关闭服务后停止。运行电脑需要持续联网。

PowerShell 指定其他端口：

```powershell
$env:PORT = '4174'
node server.mjs
```

## 平台热度口径

**这是已采集候选的综合排序，不是全网阅读量排行榜，也不是直接获取各站热榜前 20。**

| 信号 | 分值 | 算法 |
| --- | --- | --- |
| 跨站覆盖 | 35 | 1 源 0 分，2 源 17.5 分，3 源及以上 35 分 |
| 源内互动分位 | 30 | 财联社公开阅读 / 分享 / 评论，东方财富及华尔街见闻公开评论信号，各自转为源内分位；缺失计 0 |
| 时效 | 25 | `25 × exp(-小时差 / 12)` |
| 来源重点标记 | 10 | 使用列表提供的重点级别，不把未知字段当真实热度 |

多源近似标题归并后保留所有出处。近似去重和财经关键词过滤属于启发式方法，可能漏合并或误合并；不会自动把同一话题下所有不同报道都合成一条。每源每轮最多取最近约 50–100 条列表，再与当天已保存条目合并；首次启动不会补齐当天所有历史资讯。

今日必读对应平台热度前 3。新闻支持热度 / 最新 / 时间顺序、分类、前 3 筛选、关键词搜索及当前日期的本地收藏。收藏没有账号和云同步。

## 时间与降级

- “采集于”代表采集批次时间，新闻行显示来源发布时间，行情卡显示报价时间；均换算北京时间。
- SSE 心跳只表示连接在线，不改变标题采集时间；每次成功采集推送完整的当日 Top 20，前端替换榜单，避免累积超过 20 条。
- 每个来源独立采集，失败时保留已归档标题和最后成功时间。部分来源失败时有黄色标识和降级提示。
- 行情失败保留同日上次成功数据，保留红涨绿跌颜色；对应模块提示来源异常、沿用数据及上次成功采集时间。行情数字和图表不因降级变成灰色。当天分时未取得时显示为空，不把昨日分时标成今日。
- 历史日期只显示建站后实际已采集并存盘的内容。历史新闻榜单固定为当天最后一次保存的版本；新闻可在没有行情的日期独立阅读。

情绪覆盖东方财富返回的沪深京 A 股，要求完整分页且证券唯一；剔除停牌、无有效量价及非当日行情。有效样本不足候选 80% 时整批拒绝计算，保留同日上次成功指标。涨跌按最新价与昨收比较；赚钱效应为有效样本日涨跌幅中位数；市场温度为上涨家数 / 有效成交家数 × 100。页面显示候选数、有效数、剔除数、来源、范围与实际采集时间。分页采样不代表所有股票同一秒报价。

每日首次完整盘后聚合样本存入 `data/sentiment/YYYY-MM-DD.json`，不保存数千只股票明细。累计 250 份样本才计算近 250 日温度历史分位（低于当前温度的样本计 1，同值计 0.5）；不足时显示积累进度。升级前没有采集的历史情绪保持空白，不补造。已锁定的当日收盘只允许补入此前缺失的同日完整盘后情绪，显示该指标独立采集时间，原有价格和涨停统计保持。

行业热力图只展示成交额靠前的 14 个板块，资金排名基于已采集的板块样本，并非全市场完整覆盖。

收盘报价状态不代表已经编辑发布复盘。当天市场事实 JSON 与静态页面每 5 分钟更新，跨日后日档冻结；当前没有人工复盘编辑后台。之前的演示盘面保留在 `/?mode=demo&date=2026-11-09`，与默认真实页面分开。

## 1.7 自动同步与日期边界

2026-11-11 修复：旧定时任务曾出现约一小时才实际执行一次，现提高为每5分钟计划触发；这不是准点保证，GitHub仍可能排队或跳过，超过10分钟会告知延迟。网页每30秒自动读取已发布新闻、行情与日报，无需客户点击刷新；切回页面、恢复网络、午夜换日都自动同步，历史手动选择日期保持不跳转。前端文件带版本号，静态数据带请求时间参数。

开盘前的A股卡片明确写“上一交易日参考”和真实日期；今日日报不把昨收填成今日收盘。当日分时、板块、成交额、情绪与收盘结论没有产生时保持等待状态，报价到齐后自动显示。日K是历史序列，单独标注最后交易日。

全日统计边界固定为00:00（含）至24:00（不含次日），不以23:29等采样时刻作为日终统计截止。午夜至少15分钟后补采仍可获取的截止前标题，完成一次日终归档修正后固定；源列表未覆盖的消息不能声称已完整获取。数据中的cutoffAt和dayEndCompletedAt分别记录统计上界及补采完成时间，collectedAt/asOf继续记录真实来源时间，未把早先的行情时间伪装为24:00。
