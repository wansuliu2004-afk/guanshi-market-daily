# 观市 · 财经信息聚合平台

当前版本 1.3：增加免费云端定时发布模式，部署配置见 [免费上线说明.md](免费上线说明.md)。当前尚未公开上线，需要连接 GitHub 账号完成首次部署。

默认展示真实公开来源的财经标题及行情采样，新闻只保留**标题 + 来源 + 原文链接**，以及发布时间、采集时间、去重与排序所需的元数据。新闻正文和摘要不落盘、不通过本站 API 返回，也不在网页内展示。

点击标题或来源直接跳转原站；点击单独的“关联板块”按钮联动盘面。聚合标题没有站内阅读全文页。

行情卡片可直接跳转对应报价来源；分时 / 日 K、行业与资金、涨停池均有来源入口。资金排行每行也有板块来源链接，原有点击筛选资讯的操作保留。

## 自动更新和历史回看

**不用每天发消息要求更新。** 免费云端方案使用 GitHub Pages 展示网页、GitHub Actions 每 30 分钟计划采集，与个人电脑是否开机无关，历史保存在专用分支。定时任务可能延迟，网页显示真实采集时间与异常状态。需要先完成首次部署，单独打开本机网页不会自动建立公网服务。

本机预览仍可运行 `node server.mjs`，每 5 分钟自动采集一次；这个本机模式受电脑开关影响。页面会区分“本地服务”和“云端定时”，不会把本机预览标成已上线。

建站日为 **2026-11-09（北京时间）**。日期区显示建站时间、已保存天数、“已有记录”和“回到今天”。不补造建站前历史。

当天将标题 Top 20、来源链接和时间、全部已取得行情、分时、日 K、板块资金、涨停数据及事实结论合并存入 `data/archive/YYYY-MM-DD.json`。跨日后固定当天最后一次成功记录，后续抓取不覆盖已封存日期或重新计算历史榜单。因此明天选 9 号仍能看到 9 号的情况。服务重启直接读取硬盘归档，不依赖浏览器缓存。

建站前发布的资讯可以在原始采集缓存中出现，但不列入建站后日档目录。服务中断期间没有采集到的数据不会自动补齐，空日期会明确提示。日档会长期保留；迁移、重装或部署时必须一起保留整个 `data/` 目录。

## 启动

需要 Node.js 20 或以上，无需 npm 安装依赖：

```sh
node server.mjs
```

打开 **http://127.0.0.1:4173**。Windows 可双击 `启动观市.cmd`。启动时先采集一次，随后每 5 分钟采集；关闭服务后停止。运行电脑需要持续联网。

PowerShell 指定其他端口：

```powershell
$env:PORT = '4174'
node server.mjs
```

## 平台热度口径

**这是已采集候选的综合排序，不是全网阅读量排行榜，也不是直接获取各站热榜前 20。**

| 信号 | 分值 | 算法 |
| --- | --- | --- |
| 跨站覆盖 | 35 | 1 源 0 分，2 源 17.5 分，3 源及以上 35 分 |
| 源内互动分位 | 30 | 财联社公开阅读 / 分享 / 评论，东方财富及华尔街见闻公开评论信号，各自转为源内分位；缺失计 0 |
| 时效 | 25 | `25 × exp(-小时差 / 12)` |
| 来源重点标记 | 10 | 使用列表提供的重点级别，不把未知字段当真实热度 |

多源近似标题归并后保留所有出处。近似去重和财经关键词过滤属于启发式方法，可能漏合并或误合并；不会自动把同一话题下所有不同报道都合成一条。每源每轮最多取最近约 50–100 条列表，再与当天已保存条目合并；首次启动不会补齐当天所有历史资讯。

今日必读对应平台热度前 3。新闻支持热度 / 最新 / 时间顺序、分类、前 3 筛选、关键词搜索及当前日期的本地收藏。收藏没有账号和云同步。

## 时间与降级

- “采集于”代表采集批次时间，新闻行显示来源发布时间，行情卡显示报价时间；均换算北京时间。
- SSE 心跳只表示连接在线，不改变标题采集时间；每次成功采集推送完整的当日 Top 20，前端替换榜单，避免累积超过 20 条。
- 每个来源独立采集，失败时保留已归档标题和最后成功时间。部分来源失败时有黄色标识和降级提示。
- 行情失败保留同日上次成功数据，数据源状态可在“数据来源与更新说明”中查看。当天分时未取得时显示为空，不把昨日分时标成今日。
- 历史日期只显示建站后实际已采集并存盘的内容。历史新闻榜单固定为当天最后一次保存的版本；新闻可在没有行情的日期独立阅读。

## 盘面事实与复盘

真实行情接入后，原演示结论没有套用到真实数据。页面显示客观的指数、成交额和板块事实，定性主线、明日关键位及因果判断标为“待确认”。

目前未接入中国 10Y 国债收益率、完整个股样本的涨跌家数 / 赚钱效应、250 日情绪分位；这些指标保留为空。行业热力图只展示成交额靠前的 14 个板块，资金排名基于已采集的板块样本，并非全市场完整覆盖。

收盘报价状态不代表已经编辑发布复盘。当天市场事实 JSON 与静态页面每 5 分钟更新，跨日后日档冻结；当前没有人工复盘编辑后台。之前的演示盘面保留在 `/?mode=demo&date=2026-11-09`，与默认真实页面分开。

## 文件

| 文件 / 目录 | 作用 |
| --- | --- |
| `lib/collector.mjs` | 四个新闻来源适配、标题投影、去重、热度和按日归档 |
| `lib/markets.mjs` | 公开行情、分时、日 K、行业及涨跌停池适配 |
| `lib/market-sources.mjs` | 报价与市场模块的来源链接 |
| `lib/archive.mjs` | 建站时间、统一日档、跨日封存和日期目录 |
| `data/site.json` | 稳定的建站时间与数据保留说明 |
| `data/archive/YYYY-MM-DD.json` | 历史回看的完整日档，不随后续采集变化 |
| `data/news/YYYY-MM-DD.json` | 新闻元数据与来源状态；不含正文、摘要 |
| `data/markets/YYYY-MM-DD.json` | 同日市场事实记录 |
| `server.mjs` | Node 服务、五分钟调度、API 和 SSE |
| `public/app.js` | 页面交互、原文链接、筛选、虚拟列表、图表 |
| `scripts/build.mjs` | 生成 `dist/`；真实归档在 `daily/`，演示在 `demo/daily/` |
| `public/vendor/` | 本地 ECharts 5.6.0 与许可文件 |

编辑界面后运行 `node scripts/build.mjs` 并刷新浏览器。修改后端适配器需要重启服务。新闻采集与 API 需要持续运行 Node 服务；单独托管 `dist/` 不能执行采集。

## API

| 地址 | 行为 |
| --- | --- |
| `GET /api/news?date=YYYY-MM-DD` | 已缓存的当日 Top 20，含分数、来源、采集时间及排序口径 |
| `POST /api/news/refresh?date=YYYY-MM-DD` | 刷新；共享缓存，最近 60 秒内不重复拉取来源 |
| `GET /api/news/stream?date=YYYY-MM-DD` | 当前北京时间日期的榜单更新和 15 秒连接心跳 |
| `GET /api/snapshot?date=YYYY-MM-DD` | 真实市场事实；不存在则 404 |
| `GET /api/dates` | 已采集的新闻 / 盘面日期 |
| `GET /api/archive?date=YYYY-MM-DD` | 完整日档和保存 / 封存时间 |
| `GET /api/runtime` | 自动更新状态、上次完成及下次计划、建站时间 |
| `GET /api/sources` | 新闻及市场模块的采集状态 |
| `GET /health` | 服务与来源状态 |
